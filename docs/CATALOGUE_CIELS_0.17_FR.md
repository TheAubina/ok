- Overwatch : annonces/notes officielles Blizzard reprises dans le flux Steam, citant Ilios, Ecopoint et Route 66. La comparaison directe de Black Forest reste incomplète. Les décors proposés sont des interprétations.
- Lethal : [Experimentation](https://lethal.miraheze.org/wiki/Experimentation), [March](https://lethal.miraheze.org/wiki/March), [Dine](https://lethal.miraheze.org/wiki/Dine), [Offense](https://lethal.miraheze.org/wiki/Offense).

Les statuts de requêtes et les articles réellement identifiés sont consignés dans `audit-0.17/references`. Un HTTP 200 générique sans contenu pertinent n’est pas traité comme une vérification de carte.

Les ciels changent visuellement sur environ deux secondes. Le soleil, la lune et les étoiles de nuit sont rendus séparément. Les décors n’ajoutent ni bâtiments accessibles ni modifications de la météo ou de la génération. Le ciel OMORI reste indépendant du cycle jour/nuit.
