# Hina Land — bêta 0.8.0

Minecraft Java 1.20.1 · Forge 47.3.0 · Java 17

**[JAR compilé 0.8.0](https://github.com/TheAubina/ok/raw/refs/heads/main/livrables/hinaland-0.8.0.jar)** · **[Modpack de test 2 — 22 JAR](https://github.com/TheAubina/ok/raw/refs/heads/main/livrables/HinaLand-0.8.0-modpack-test-2.zip)**

Douze biomes dans l’Overworld : plaines, forêts, hauts plateaux et dunes pour Mario, Sonic et OMORI. Régions agrandies et proportion vanilla réduite dans la configuration du pack. Roche, minerais, arbres, sable, grès, gravier et rochers thématiques générés naturellement.

## Installation

Remplacer l’ancien JAR Hina Land par 0.8.0 ; ne pas garder les deux. Le JAR seul nécessite GeckoLib 4.4.9 et TerraBlender 3.0.1.7.

Le modpack contient `mods`, `config` et `resourcepacks`. Copier la configuration `terrablender.toml` pour obtenir les régions agrandies et le poids vanilla réduit. Activer HinaLand-integration-textures.zip. **Créer un nouveau monde** pour voir la nouvelle génération ; les anciens chunks restent inchangés.

## Validations et limites

Onze GameTests Forge réussis, douze sites naturels vérifiés dans les chunks sauvegardés, client et serveur de production chargés avec les 22 JAR. Ciel OMORI observé dans la nouvelle forêt. Sur une graine et une grille identiques, les points terrestres Hina Land passent de 16,5 % à 82,1 % ; ce n’est pas une proportion garantie pour tous les mondes.

Lunaria Media manque au paquet et trois succès restent bloqués. Les structures, autres univers, boss et comportements complets Lethal restent à terminer. Les tests ne valident pas une campagne complète de Survie ou chaque mécanique des mods personnels.
