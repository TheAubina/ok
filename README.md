# Hina Land — bêta 0.7.0

Mod Minecraft Java 1.20.1 pour Forge 47.3.0 et Java 17.

[Téléchargements de la release](https://github.com/TheAubina/ok/releases/tag/v0.7.0-beta.1)

[JAR compilé](https://github.com/TheAubina/ok/raw/refs/heads/main/livrables/hinaland-0.7.0.jar) · [Modpack de test](https://github.com/TheAubina/ok/raw/refs/heads/main/livrables/HinaLand-0.7.0-modpack-test-1.zip)

La release propose le JAR Hina Land compilé et un paquet de modpack contenant 22 JAR. Pour le JAR seul, installer également GeckoLib 4.4.9 et TerraBlender 3.0.1.7. Le paquet inclut ces dépendances.

Le paquet contient les dossiers `mods`, `config` et `resourcepacks`. Activer le pack de ressources HinaLand-integration-textures.zip dans Minecraft.

**Bêta incomplète :** Lunaria Media 2.0.2 manque au paquet et trois succès de quête sont bloqués. Les contrôles de chargement ne valident pas toutes les mécaniques des mods. Les comportements Lethal, structures, boss et autres fonctionnalités restent à développer ou à tester selon le rapport.
